# Sprite art

Generated with the built-in `image_gen` tool, then edited with the same tool to remove residual white background. Final production asset: `assets/whip-atlas.png`. The generated atlas is divided into 16 equal cells at runtime; retain its square 4 × 4 layout when replacing it.

## Generation prompt

Use case: stylized-concept. Asset type: production 2D game sprite atlas for a funny Windows desktop whip toy. Generate ONE square PNG with genuine transparent background, perfectly regular 4 columns by 4 rows of equal square cells, no gutters, no borders, no text. Exactly 16 separate sprites, all safely inside their cell with 12% empty padding, no overlap. Reading order: first 8 cells (first two rows) show 8 successive animation frames of the SAME brown leather whip with short wooden handle: resting curl, raised coil, backswing, uncoiling, fast forward lash, fully extended downward-right lash, curling recovery, resting curl. Handle pivot fixed near lower-left of each cell (25% from left, 75% from top); same camera scale. Last 8 cells (bottom two rows) show 8 successive frames of an impact VFX centered in each cell: tiny yellow spark, growing yellow-orange comic starburst, large bright starburst with white core, peak burst, expanding orange ring with sparks, fading scattered sparks, few tiny sparks, final very faint spark. Thick crisp dark outlines on whip, playful hand-painted cartoon game art, clean readable silhouettes, warm amber palette. No people, no injury, no blood, no lettering, no checkerboard baked into image. Every cell is one animation frame.

## Cleanup prompt

Edit this sprite atlas. Preserve all 16 sprites, exact positions and equal 4x4 grid, and their appearance. Remove ALL white background from the bottom two rows and all white background contamination along horizontal middle boundary. Entire background must be actual transparent alpha throughout image, including spaces between sparks and inside the orange ring. Keep the white luminous cores INSIDE the starburst sprites. No white backdrop, no black backdrop, no checkerboard. Clean transparent game sprite atlas.

## Playback

Frames 0–7: whip animation. Frames 8–15: contact VFX, centered on the clicked desktop point. AI-generated poses have small alignment variations; the runtime uses a fixed cell rectangle, so review temporal consistency before replacing this first-pass atlas with polished hand-corrected art. `preview.png` is generated by `--self-test` and is not source art.
