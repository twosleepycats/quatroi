# Application icon

Generated using the built-in `image_gen` tool. Original image: `assets/app-icon.png`. Windows ICO packaging: `scripts/build-icon.ps1`, producing `assets/app.ico` with seven sizes. Both the executable and tray use this icon.

## Prompt

Use case: logo-brand. Create a single Windows desktop app icon for a playful whip cursor toy named Quat Roi. No text or letters. One bold stylized golden brown leather whip with a short chunky wooden handle, curled cord forming a simple large loop, and one small amber comic spark at the tip. Handle points diagonally upward from lower right toward upper left. Very simple crisp silhouette, thick dark brown outlines, minimal details, warm highlights, friendly cartoon game style. Center the whole object in a square with generous 12% safe padding, readable at 16x16 pixels. Genuine transparent background outside the object. No frame, no icon tile, no shadow backdrop, no extra objects, no people.
